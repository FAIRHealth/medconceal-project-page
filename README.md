# MedConceal project page

Project website for **MedConceal: A Benchmark for Clinical Hidden-Concern Reasoning Under Partial Observability** (COLM 2026).

Authors: Yikun Han, Joey Chan, Jingyuan Chen, Mengting Ai, Simo Du, and Yue Guo.

## Resources

- [Benchmark code and resources](https://github.com/FAIRHealth/MedConceal)
- [Dataset](https://huggingface.co/datasets/Eclipse42/MedConceal)
- [Paper](assets/medconceal-paper.pdf)

## Local preview

Open `index.html` directly, or run `python -m http.server 8765 --bind 127.0.0.1` from this directory and visit http://127.0.0.1:8765/.

No dependencies or build step are required. Edit `index.html` for content, `styles.css` for presentation, and `script.js` for the interactive case and result views.

## GitHub Pages

Publish from the `main` branch and `/ (root)` directory in Settings > Pages. Pushing subsequent commits to `main` republishes the website.
